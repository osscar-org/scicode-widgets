Contributing
============

Please read the `developer documentation <https://scicode-widgets.readthedocs.io/en/latest/developers.html>`_.

`GitHub issue <https://github.com/osscar-org/scicode-widgets/issues/new>`_. For
support requests, please contact any of the people listed below:
